## 📋 نظرة عامة

نظام ERP شامل لجامعة القاهرة الجديدة التكنولوجية يدعم إدارة الطلاب والأساتذة والمواد الدراسية والدرجات والمدفوعات مع واجهة مستخدم حديثة ومتجاوبة.

## ✨ المميزات الرئيسية

### 👥 إدارة المستخدمين
- **أنواع المستخدمين**: مدير، أستاذ، طالب، محاسب، مسجل
- **نظام مصادقة آمن**: JWT مع تشفير كلمات المرور
- **صلاحيات مرنة**: تحكم دقيق في الوصول لكل نوع مستخدم

### 📚 إدارة المواد والتخصصات
- **6 تخصصات تقنية**: الميكاترونكس، الأوتوترونكس، تكنولوجيا المعلومات، الأطراف الصناعية، إنتاج البترول، الطاقة المتجددة
- **مواد مشتركة**: رياضيات، فيزياء، إنجليزي
- **نظام تسجيل ذكي**: ربط الطلاب بالمواد حسب التخصص

### 🎯 إدارة الدرجات (الأهم!)
- **قيود الأساتذة**: كل أستاذ يدخل درجات مادته فقط
- **حساب تلقائي**: GPA ونسب المئوية والتقديرات
- **مراحل الموافقة**: مسودة → مقدم → معتمد → منشور

### 💰 إدارة المالية
- **الفواتير**: إنشاء وإدارة فواتير الطلاب
- **المدفوعات**: تتبع المدفوعات والمبالغ المستحقة
- **التقارير المالية**: إحصائيات شاملة

### 📱 واجهة المستخدم
- **تصميم متجاوب**: يعمل على جميع الأجهزة
- **دعم اللغة العربية**: RTL كامل
- **رسوم متحركة**: GSAP + Framer Motion
- **تجربة مستخدم ممتازة**: تصميم حديث وأنيق

### 🤖 الذكاء الاصطناعي والدردشة
- **Botpress Chatbot**: مساعد ذكي للطلاب يجيب على الأسئلة باللغة الطبيعية
- **استعلامات فورية**: الدرجات، المدفوعات، المواد، الجدول الدراسي، رقم المقعد
- **دعم 24/7**: مساعدة على مدار الساعة دون الحاجة للبحث اليدوي
- **تكامل كامل**: يستخدم نفس قاعدة البيانات للمعلومات الدقيقة

## 🛠️ التقنيات المستخدمة

### الواجهة الأمامية (Frontend)
- **React 18** مع **Vite** لبناء سريع
- **React Router DOM** للتنقل
- **Zustand** لإدارة الحالة
- **Axios** للتواصل مع الخادم
- **GSAP** و **Framer Motion** للرسوم المتحركة
- **Recharts** للرسوم البيانية
- **React Hot Toast** للإشعارات
- **QRCode.react** لإنتاج رموز QR
- **Botpress Webchat** للدردشة الذكية

### الخادم الخلفي (Backend)
- **Node.js** مع **Express.js**
- **Sequelize ORM** لقاعدة البيانات
- **MySQL** كقاعدة بيانات
- **JWT** للمصادقة
- **bcryptjs** لتشفير كلمات المرور
- **multer** لرفع الملفات
- **qrcode** لإنتاج رموز QR
- **pdfkit** لإنتاج ملفات PDF

## 🚀 التثبيت والتشغيل

### متطلبات النظام
- **Node.js** 18.x أو أحدث
- **MySQL** 8.0 أو أحدث
- **npm** أو **yarn**

### خطوات التثبيت

1. **استنساخ المشروع**
   ```bash
   git clone https://github.com/your-username/nctu-erp.git
   cd nctu-erp
   ```

2. **تثبيت الخادم**
   ```bash
   cd server
   npm install
   ```

3. **تثبيت الواجهة الأمامية**
   ```bash
   cd ../client/frontend
   npm install
   npm install @botpress/webchat @botpress/webchat-generator
   ```

4. **إعداد قاعدة البيانات**
   ```bash
   # إنشاء قاعدة البيانات
   mysql -u root -p < database/nctu_erp.sql
   ```

5. **تكوين متغيرات البيئة**
   - عدل ملف `server/.env` لإعدادات قاعدة البيانات
   - عدل ملف `client/frontend/.env` لإعدادات API و Botpress:
     ```env
     REACT_APP_API_URL=http://localhost:5000
     REACT_APP_BOTPRESS_CLIENT_ID=your-botpress-client-id
     REACT_APP_BOTPRESS_WEBHOOK_ID=your-botpress-webhook-id
     ```

6. **إعداد Botpress (اختياري)**
   - أنشئ حساب على [Botpress Cloud](https://botpress.cloud)
   - أنشئ bot جديد وانسخ Client ID و Webhook ID
   - راجع ملف `BOTPRESS_SETUP.md` للتعليمات التفصيلية

6. **تشغيل الخادم**
   ```bash
   cd server
   npm start
   ```

7. **تشغيل الواجهة الأمامية**
   ```bash
   cd ../client/frontend
   npm run dev
   ```
